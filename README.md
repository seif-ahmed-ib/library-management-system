# Library Management System

A backend Library Management System built with FastAPI as a group project for the R and Python Programming Language course.

## Project Overview

The system allows librarians to manage books and borrowing records, while members can borrow and return available books and view their borrowing history.

## Main Features

- User registration and login using JWT authentication
- Role-based access for Admin and Member
- Book management: create, view, update, and delete
- Borrow and return books
- Check book availability before borrowing
- Limit the number of active borrowed books per member
- View personal and complete borrowing history
- Redis caching
- Structured logging and monitoring
- Automated testing

## Technologies

- Python 3.11
- FastAPI
- SQLAlchemy
- SQL Server
- Redis
- Pytest
- Git and GitHub
